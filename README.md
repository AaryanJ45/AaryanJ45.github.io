# aaryanj45.github.io

My resume as a website, typeset to look like the LaTeX PDF (Latin Modern Roman, Jake's Resume layout). Plain HTML and CSS, no build step; GitHub Pages serves `main`.

To update: edit `index.html`, and replace `Aaryan_Jadhav_Resume.pdf` with the new PDF.

Fonts: Latin Modern, under the GUST Font License (`fonts/GUST-FONT-LICENSE.TXT`).
